# Review checklist (before export)

**Story**
- [ ] Hook lands in the first 5 seconds
- [ ] Cut anything that doesn't serve the promise
- [ ] Clear call to action

**Picture**
- [ ] Consistent color/exposure between clips
- [ ] No jump-cut glitches or flash frames
- [ ] Graphics/text readable on a phone, inside safe margins

**Audio**
- [ ] Dialogue clear, levels consistent (-14 LUFS for web)
- [ ] Music ducks under speech
- [ ] No clicks, pops or room noise

**Delivery**
- [ ] Captions checked
- [ ] Watched start to finish on the target device
- [ ] File name and version correct
