# Folder structure & naming

```
<project>/
  01_raw/        untouched camera/audio files (never edit in place)
  02_assets/     music, SFX, graphics, fonts, LUTs
  03_project/    editor project files + autosaves
  04_exports/    renders: v1, v2, final
  05_publish/    thumbnail, captions, description
```

## Naming

- Project folder: `YYYY-MM-DD-slug`
- Raw clips: `YYYYMMDD_scene_take` (e.g. `20261007_intro_03`)
- Exports: `slug_v01.mp4`, `slug_final.mp4`
- Never rename or move raw files after ingest.

## Backup

3-2-1: 3 copies, 2 media types, 1 offsite. Back up `01_raw` at ingest and `03_project` at end of each session.
